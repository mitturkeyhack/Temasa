# Temâşâ

Reklamsız YouTube uygulaması — Erkam Yazılım.

- YouTube düzeninin aynısı: ana sayfa, abonelikler, arama, kanal, oynatma listeleri
- Reklam yok, Shorts yok
- Arka planda ve ekran kapalıyken oynatma, küçük pencere (PiP)
- 144p'den 4K'ya kalite, 0.25x–4x hız (kanal başına hatırlanır), basılı tut = 2x
- Uygulama içi indirme (galeride görünmez), internetsiz izleme
- Google ile oturum aç: abone ol, beğen, Sonra izle YouTube hesabına işlenir
- Sponsor atlama, beğenmeme sayısı, bölümler, altyazı, uyku zamanlayıcı
- YouTube bağlantılarını ve paylaşımları açar
